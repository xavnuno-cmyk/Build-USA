# Build USA

Aplicación web instalable para convertir milímetros a pies, pulgadas y octavos.

## Configuración en Cloudflare Pages

- Framework preset: None
- Build command: dejar vacío
- Build output directory: /
- Root directory: /

No usa cuentas de usuario, cookies, analítica, bases de datos ni servicios externos.

## Pruebas

- 25,4 mm → 0' 1"
- 304,8 mm → 1' 0"
- 1000 mm → 3' 3 3/8"
